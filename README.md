# AniShelf365

**Локальная медиатека для аниме с интеграцией аниме365.**

Скачивайте серии с субтитрами, храните их локально и смотрите во внешнем VLC — всё в одном приложении.

---

## ✨ Возможности

- 📚 **Библиотека тайтлов** — сетка плиток с обложками, поиск, сортировка, фильтры
- 📺 **Список серий** — с фильтрами по типу перевода (sub / voice / raw) и языку (ru / en / ja)
- ⬇️ **Скачивание** — параллельная загрузка через HTTP Range, докачка при обрывах, очередь
- 🎬 **Воспроизведение** — внешний VLC с авто-подключением субтитров `.ass`
- 🗑️ **Удаление** — по одному эпизоду или всё скачанное в тайтле
- 🎨 **Тёмная и светлая темы**, локализация RU / EN

## 🚀 Установка

### Требования

- Python **3.10+**
- **VLC media player** (для воспроизведения)
  - Windows: [скачать](https://www.videolan.org/vlc/)
  - Linux: `sudo apt install vlc`
  - macOS: [скачать](https://www.videolan.org/vlc/)

### Шаги

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/ВАШ_НИК/anishelf365.git
   cd anishelf365
   ```

2. **Создайте виртуальное окружение** (рекомендуется)

   ```bash
   python -m venv .venv
   .venv\Scripts\activate    # Windows
   source .venv/bin/activate # Linux/macOS
   ```

3. **Установите зависимости**

   ```bash
   pip install -r requirements.txt
   ```

4. **Получите токен Anime365**

   - Зарегистрируйте приложение: [https://smotret-anime.org/api/clients](https://smotret-anime.org/api/clients)
   - Получите `access_token` через `/api/login` или `/api/accessToken`
   - Сохраните токен в `data/token.json`:

     ```json
     {
       "access_token": "ваш_токен"
     }
     ```

5. **Запустите приложение**

   ```bash
   python main.py
   ```

   При первом запуске откроется **онбординг** — выберите язык, тему, папку библиотеки, проверьте VLC, вставьте токен.

## 🎮 Использование

### Добавление тайтла

1. Нажмите **«+ Добавить»** в библиотеке.
2. Вставьте ссылку на тайтл с аниме365 (например, `https://smotret-anime.org/catalog/yani-neko-41893`) или введите ID.
3. Метаданные и обложка подгрузятся автоматически.

### Скачивание серий

1. Откройте тайтл.
2. Кликните **«⬇»** на нужной серии.
3. Выберите перевод и качество → **«⬇ Скачать»**.
4. Скачивание пойдёт в фоне — можно продолжать работать или добавить ещё серии в очередь.

### Просмотр

1. Кликните **«▶»** на скачанной серии.
2. Откроется **VLC** с видео и подключёнными субтитрами `.ass`.
3. Серия автоматически помечается просмотренной.

## 🛠️ Технологии

- **Python 3.10+**
- **PySide6** — современный Qt-интерфейс с GPU-рендерингом
- **SQLite** — локальная база данных
- **requests** — HTTP-запросы к API
- **Pillow** — обработка обложек
- **python-vlc** — интеграция с VLC (в разработке)
